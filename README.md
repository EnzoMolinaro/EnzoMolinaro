## 🚀 Projetos em Destaque

### 📚 [API de Gestão de Biblioteca](https://github.com/EnzoMolinaro/biblioteca-api)
> **Java • Spring Boot • Spring Security • PostgreSQL • Docker • GitHub Actions**

API REST para gerenciamento de biblioteca (livros, usuários, empréstimos).

- Autenticação JWT e controle de acesso por perfis (RBAC)
- Regras de negócio: disponibilidade de acervo, limite de empréstimos, cálculo automático de multas
- Paginação, filtros dinâmicos e tratamento centralizado de exceções (`@ControllerAdvice`)
- Arquitetura em camadas, com cobertura de testes acima de 75% (JUnit 5 e Mockito)
- Pipeline de CI/CD com GitHub Actions, rodando em Docker

---

### 📦 [FerroFlux — sistema para a Seiti Sucatas](https://github.com/EnzoMolinaro/FerroFlux)
> **Python • SQL Server • pyodbc • CustomTkinter** · Projeto em grupo

Software desktop feito sob medida para uma empresa real, desenvolvido em grupo ao longo de toda a graduação, a partir de requisitos levantados direto com o usuário final.

- Controle de estoque e financeiro, com registro completo das movimentações (data, hora e operador)
- Controle de acesso por perfil (admin e operador)
- Modelagem do banco de dados com diagramas, seguindo as regras de negócio

---

### ⚽ [Copa do Mundo Feminina — site de dados históricos](https://github.com/EnzoMolinaro/Copa_do_mundo_feminina)
> **PHP (majoritariamente puro, com contato inicial em Laravel) • MySQL**

Projeto individual: um site que organiza e disponibiliza um grande volume de dados históricos da Copa do Mundo de Futebol Feminino, pensado para apoiar pesquisas sobre o tema.

- Coleta, tratamento e organização de um grande volume de dados históricos
- Modelagem do banco de dados em MySQL e backend em PHP, feitos sozinho do início ao fim
- Sem necessidade de login ou autenticação; o foco é a correção e a acessibilidade dos dados

*(repositório em atualização)*

---

### 🔔 notification-service — notificações de empréstimo atrasado
> **Java • Spring Boot • Spring AMQP • RabbitMQ • Docker Compose**

Microsserviço independente que consome eventos publicados no RabbitMQ (Topic Exchange) e dispara alertas.

- Contratos de eventos em JSON, para evolução independente entre serviços
- Job agendado (Spring Scheduler) com controle de idempotência, evitando notificações duplicadas
- Monitoramento das filas pelo painel do RabbitMQ
