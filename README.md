## 🚀 Projetos em Destaque

### 🔐 [API de Gestão de Usuários](https://github.com/EnzoMolinaro/user-management-api)
> **Java • Spring Boot • Spring Security • PostgreSQL • Docker • JWT**

Sistema completo de autenticação e gestão de usuários com controle de acesso baseado em perfis.

- Autenticação JWT com refresh tokens
- Controle de acesso por roles (ADMIN, USER)
- Validações robustas e tratamento de erros
- Testes unitários com JUnit e Mockito
- Containerização com Docker e Docker Compose

**Destaques técnicos:** Implementação de segurança em camadas, bcrypt para senhas, DTOs para separação de responsabilidades.

---

### 📚 [Sistema de Gestão de Biblioteca](https://github.com/EnzoMolinaro/library-management-system)
> **Java • Spring Boot • JPA/Hibernate • MySQL • REST API**

API REST para gerenciamento completo de biblioteca (livros, usuários, empréstimos).

- CRUD completo de livros, usuários e empréstimos
- Modelagem relacional complexa com relacionamentos N:N
- Regras de negócio: limite de empréstimos, multas por atraso, reservas
- Validações customizadas e exceções personalizadas
- Documentação com Swagger/OpenAPI

**Destaques técnicos:** Arquitetura em camadas (Controller → Service → Repository), tratamento de transações, queries otimizadas.

---

### ⚙️ [Pipeline CI/CD com Deploy Automatizado](https://github.com/EnzoMolinaro/cicd-pipeline-demo)

Pipeline completo de integração e deploy contínuo para aplicação Spring Boot.

- Build automatizado com Maven

- Deploy automatizado em ambiente cloud
- Notificações de status do pipeline
